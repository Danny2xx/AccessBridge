# Evaluation

This file is generated by `scripts/write_evaluation.py` from the active
travel-time matrix, so the figures below always match the site and the API.

The active matrix is routed with R5. Walking times follow the OpenStreetMap
street network (Geofabrik west-midlands-latest.osm.pbf, 22 Sep 2026 23:28:35)
at 80 metres a minute. Bus and Metro legs are not included, so a stop counts
as reached only on foot. The walk-plus-transit matrix from the same build is
saved beside it for comparison.

Regenerate with:

```bash
.venv/bin/python scripts/write_evaluation.py
```

## 5. Routed walking times against the straight-line proxy

The same default request on the Stage 0 proxy matrix, which estimated every walk
as a straight line at 80 metres a minute, gives a different picture of reach:

| Matrix | Stops | Most-deprived reached | Reached today | Gain |
|---|---:|---:|---:|---:|
| Straight-line proxy | 7 | 126,330 | 71,309 | 55,021 |
| Routed on streets (active) | 7 | 103,650 | 48,360 | 55,290 |

Real streets make walks longer, so both the baseline and the optimised reach
fall. The gain is the more robust figure, and the routed one is the one to quote.
